# 마커 클러스터링

네이버 지도 라이브러리에서 제공하는 내장 마커 클러스터링 기능을 사용하여 많은 수의 마커를 효율적으로 표시할 수 있습니다.

<Callout type="info">
  마커 클러스터링은 지도 상의 가까운 거리에 있는 여러 마커들을 하나의 클러스터로 묶어 표시하는 기법입니다.
  네이버 지도 라이브러리는 이 기능을 네이티브 레벨에서 지원하므로 별도의 외부 라이브러리가 필요하지 않습니다.
</Callout>

## 기본 클러스터링 구현

네이버 지도의 클러스터링은 `NaverMapView` 컴포넌트의 `clusters` 속성을 통해 설정할 수 있습니다.

### 1. ClusterMarkerProp 타입 정의

클러스터에 포함될 각 마커는 `ClusterMarkerProp` 타입을 준수해야 합니다:

```tsx
import type { ClusterMarkerProp } from '@mj-studio/react-native-naver-map';

const clusterMarkers: ClusterMarkerProp[] = [
  {
    identifier: 'marker-1',
    latitude: 37.5665,
    longitude: 126.9780,
    image: { symbol: 'red' }, // 또는 { httpUri: 'https://...' }, { assetName: 'marker' } 등
    width: 40,
    height: 40,
  },
  {
    identifier: 'marker-2',
    latitude: 37.5675,
    longitude: 126.9785,
    image: { symbol: 'blue' },
    width: 40,
    height: 40,
  },
  // ... 더 많은 마커들
];
```

### 2. 기본 클러스터링 구현

```tsx
import React, { useState, useMemo } from 'react';
import { View } from 'react-native';
import { NaverMapView, type ClusterMarkerProp } from '@mj-studio/react-native-naver-map';

const ClusteredMapExample = () => {
  // 마커 데이터 생성
  const clusterMarkers = useMemo<ClusterMarkerProp[]>(() => {
    return generateMarkerData().map((marker, index) => ({
      identifier: `marker-${index}`,
      latitude: marker.latitude,
      longitude: marker.longitude,
      image: { httpUri: `https://picsum.photos/32/32?random=${index}` },
      width: 32,
      height: 32,
    }));
  }, []);

  // 클러스터 설정
  const clusters = useMemo(() => [
    {
      width: 50,          // 클러스터 마커의 너비
      height: 50,         // 클러스터 마커의 높이
      markers: clusterMarkers,
      screenDistance: 40, // 클러스터링 기준 화면 거리 (픽셀)
      minZoom: 5,         // 클러스터링할 최소 줌 레벨
      maxZoom: 18,        // 클러스터링할 최대 줌 레벨
      animate: true,      // 클러스터 펼침/합침 애니메이션
    }
  ], [clusterMarkers]);

  return (
    <NaverMapView
      style={{ flex: 1 }}
      initialCamera={{
        latitude: 37.5665,
        longitude: 126.9780,
        zoom: 10,
      }}
      clusters={clusters}
      onTapClusterLeaf={({ markerIdentifier }) => {
        console.log('마커 클릭됨:', markerIdentifier);
      }}
    />
  );
};
```

## 고급 클러스터링 설정

### 집계 클러스터 마커 꾸미기

클러스터 그룹의 `image`, `width`, `height`, `caption`을 지정하면 가까운 여러 항목을 대표하는 집계 클러스터 마커를 꾸밀 수 있습니다. 이 속성들은 `markers` 안의 개별 단말(leaf) 마커를 바꾸지 않습니다. 각 단말 마커는 자신의 `image`, `width`, `height`를 그대로 사용합니다.

```tsx
import {
  type ClusterMarkerCaption,
  NaverMapView,
} from '@mj-studio/react-native-naver-map';

const clusterCaption = {
  color: '#fde047',
  haloColor: '#111827',
  textSize: 16,
  align: 'Center',
} satisfies ClusterMarkerCaption;

<NaverMapView
  style={{ flex: 1 }}
  clusters={[
    {
      image: { symbol: 'red' },
      width: 64,
      height: 64,
      caption: clusterCaption,
      markers: clusterMarkers,
    },
  ]}
/>
```

예제는 `caption.text`를 생략했으므로 각 집계 마커에 현재 구성원 수를 표시합니다. `text`에 문자열을 지정하면 그룹의 모든 집계 마커에 같은 고정 텍스트를 표시하고, 빈 문자열을 지정하면 캡션을 숨깁니다. 동적으로 텍스트를 만드는 formatter와 React 콘텐츠는 지원하지 않습니다.

`caption`을 생략하면 SDK가 구성원 수를 가운데에 표시합니다. 기본 스타일은 흰색 텍스트, 투명한 외곽선, 텍스트 크기 `12`, 너비와 간격 `0`, 캡션 줌 범위 `0`~`21`입니다. 부분적인 `caption` 객체에서 생략한 필드에도 같은 기본값을 적용합니다. 캡션 필드는 일반 마커 캡션과 같은 이름과 단위를 사용합니다. 지원하는 필드는 `requestedWidth`, `align`, `offset`, `color`, `haloColor`, `textSize`, `minZoom`, `maxZoom`입니다.

`width`와 `height`는 React Native의 논리적 레이아웃 단위를 사용합니다. `image`를 생략하면 SDK가 구성원 수에 따라 저밀도, 중밀도, 고밀도 클러스터 아이콘을 선택합니다. 알 수 없는 symbol이나 URI 불러오기 실패처럼 이미지 해석 결과가 없으면 녹색 대체 이미지를 사용합니다. asset이나 네트워크 이미지는 클러스터 그룹을 지도에 연결하기 전에 불러오므로, 집계 마커와 단말 마커를 포함한 그룹 전체가 이미지 결과를 기다립니다. 네트워크 연결 없이 그룹을 표시해야 한다면 번들 asset이나 기본 symbol을 사용하세요.

그룹의 이미지, 캡션, 크기를 바꾸면 해당 클러스터 그룹을 새 스타일로 다시 만듭니다. 스타일을 바꿔도 집계 마커를 탭했을 때 클러스터가 펼쳐질 때까지 지도를 확대하는 SDK 기본 동작은 유지됩니다.

### 다중 클러스터 그룹

서로 다른 설정을 가진 여러 클러스터 그룹을 동시에 사용할 수 있습니다:

```tsx
const multiClusters = useMemo(() => [
  {
    // 첫 번째 클러스터 그룹 - 일반 마커들
    width: 40,
    height: 40,
    markers: regularMarkers,
    screenDistance: 50,
    minZoom: 5,
    maxZoom: 15,
    animate: true,
  },
  {
    // 두 번째 클러스터 그룹 - 특별한 마커들
    width: 60,
    height: 60,
    markers: specialMarkers,
    screenDistance: 80,
    minZoom: 8,
    maxZoom: 20,
    animate: false,
  }
], [regularMarkers, specialMarkers]);
```

## 클러스터 이벤트 처리

### 집계 클러스터 마커 탭 이벤트

`onTapCluster`를 사용하면 네이티브 SDK가 탭한 집계 클러스터에 포함한 마커를 받을 수 있습니다. `clusterIndex`는 현재 `clusters` 배열에서 해당 그룹의 인덱스이고, `markerIdentifiers`는 해당 클러스터에 속한 모든 하위 마커의 식별자입니다.

```tsx
import type { ClusterMarkerTapParams } from '@mj-studio/react-native-naver-map';

const handleTapCluster = ({
  clusterIndex,
  markerIdentifiers,
}: ClusterMarkerTapParams) => {
  const markerIdentifierSet = new Set(markerIdentifiers);
  const tappedMarkers = clusters[clusterIndex].markers.filter(({ identifier }) =>
    markerIdentifierSet.has(identifier),
  );

  showClusterItems(tappedMarkers);
};

<NaverMapView
  clusters={clusters}
  onTapCluster={handleTapCluster}
/>
```

식별자로 원래 마커 데이터를 찾을 수 있도록 각 클러스터 그룹 안에서 마커 식별자를 고유하게 지정하세요. `markerIdentifiers`의 순서는 정해져 있지 않습니다. SDK 기본 동작에 따라 클러스터가 펼쳐질 때까지 지도를 확대합니다. 콜백은 탭한 시점의 구성원을 전달하며, 확대를 취소하거나 지연하지 않습니다.

### 개별 마커 클릭 이벤트

클러스터에 포함된 개별 마커가 클릭되었을 때의 이벤트를 처리할 수 있습니다:

```tsx
<NaverMapView
  clusters={clusters}
  onTapClusterLeaf={({ markerIdentifier }) => {
    // markerIdentifier를 사용하여 해당 마커의 상세 정보 표시
    const markerData = findMarkerById(markerIdentifier);
    showMarkerDetail(markerData);
  }}
/>
```

## Overview

Use `useInfoWindow` for a text InfoWindow with the SDK's default speech bubble. Use `NaverMapInfoWindow` when the entire InfoWindow should be rendered from a custom React view. Both APIs can open the same InfoWindow on a `NaverMapMarkerOverlay` or at a map coordinate and close it manually.

Use one hook or component instance for each InfoWindow you want to manage. Each instance owns its native InfoWindow for its mounted lifetime.

## Show Custom React Content

Mount `NaverMapInfoWindow` directly under `NaverMapView`. It accepts exactly one React view child. Give that child explicit, non-zero dimensions. The component preserves the child's native view automatically.

The child owns the entire visual, including its background or speech-bubble shape. The view is rasterized into an overlay image for the NAVER Map SDK, so controls such as `Button` and `TextInput` inside it are not live interactive controls.

```tsx
import { useRef, useState } from 'react';
import { Button, Text, View } from 'react-native';
import {
  NaverMapInfoWindow,
  type NaverMapInfoWindowRef,
  NaverMapMarkerOverlay,
  type NaverMapMarkerOverlayRef,
  NaverMapView,
} from '@mj-studio/react-native-naver-map';

function CustomInfoWindowMap() {
  const markerRef = useRef<NaverMapMarkerOverlayRef>(null);
  const infoWindowRef = useRef<NaverMapInfoWindowRef>(null);
  const [revision, setRevision] = useState(1);

  return (
    <View style={{ flex: 1 }}>
      <NaverMapView style={{ flex: 1 }}>
        <NaverMapMarkerOverlay
          ref={markerRef}
          latitude={37.5547}
          longitude={126.9707}
          onTap={() => {
            infoWindowRef.current?.showOnMarker({ markerRef });
          }}
        />
        <NaverMapInfoWindow ref={infoWindowRef}>
          <View
            style={{
              width: 140,
              height: 56,
              borderRadius: 8,
              backgroundColor: '#1d4ed8',
              alignItems: 'center',
              justifyContent: 'center',
            }}
          >
            <Text style={{ color: 'white' }}>Revision {revision}</Text>
          </View>
        </NaverMapInfoWindow>
      </NaverMapView>
      <Button
        title="Update content"
        onPress={() => setRevision((value) => value + 1)}
      />
    </View>
  );
}
```

Changes passed from the parent, such as `revision` in the example, automatically redraw an open InfoWindow after the React commit. If child-local state changes or an asynchronous image finishes loading without changing the child element passed by the parent, call `infoWindowRef.current?.invalidate()` after that commit. `invalidate()` redraws the current content; it does not open the InfoWindow.

## Show Text On A Marker

`useInfoWindow` creates the SDK's default text InfoWindow. It updates the text and placement options when the hook content changes.

```tsx
import { useRef } from 'react';
import {
  NaverMapMarkerOverlay,
  NaverMapView,
  type NaverMapMarkerOverlayRef,
  useInfoWindow,
} from '@mj-studio/react-native-naver-map';

function MarkerInfoWindowMap() {
  const markerRef = useRef<NaverMapMarkerOverlayRef>(null);
  const infoWindow = useInfoWindow({
    text: 'Seoul Station',
    anchor: { x: 0.5, y: 1 },
    offset: { x: 0, y: -8 },
    alpha: 0.9,
  });

  return (
    <NaverMapView style={{ flex: 1 }}>
      <NaverMapMarkerOverlay
        ref={markerRef}
        latitude={37.5547}
        longitude={126.9707}
        onTap={() => {
          infoWindow.showOnMarker({ markerRef, alignType: 'Right' });
        }}
      />
    </NaverMapView>
  );
}
```

## Show Text At A Map Coordinate

```tsx
import { useRef } from 'react';
import {
  NaverMapView,
  type NaverMapViewRef,
  useInfoWindow,
} from '@mj-studio/react-native-naver-map';

function MapInfoWindow() {
  const mapRef = useRef<NaverMapViewRef>(null);
  const infoWindow = useInfoWindow({
    text: 'Hangang Bridge',
  });

  return (
    <NaverMapView
      ref={mapRef}
      style={{ flex: 1 }}
      onTapMap={() => {
        infoWindow.showOnMap({
          mapRef,
          position: { latitude: 37.5219, longitude: 126.9918 },
        });
      }}
    />
  );
}
```

## Close And Readiness

The hook and component ref expose the same `showOnMarker`, `showOnMap`, and `close` controls. The show methods return `false` when the target ref is not ready. Use the return value when UI state should only change after the native command is actually sent.

```tsx
const didShow = infoWindow.showOnMarker({ markerRef });
if (!didShow) return;

infoWindow.close();
```

`NaverMapInfoWindowRef`

| Method | Description |
| --- | --- |
| `showOnMap({ mapRef, position })` | Opens the InfoWindow at a map coordinate. Returns `false` when `mapRef.current` is not ready. |
| `showOnMarker({ markerRef, alignType })` | Opens the InfoWindow on a marker. Returns `false` when `markerRef.current` is not ready. |
| `close()` | Closes the InfoWindow. |
| `invalidate()` | Redraws the current custom React content. |

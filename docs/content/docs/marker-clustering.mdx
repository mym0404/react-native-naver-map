# Marker Clustering

You can efficiently display a large number of markers using the built-in marker clustering feature provided by the Naver Map library.

<Callout type="info">
  Marker clustering is a technique that groups multiple markers at close distances on the map into a single cluster for display.
  The Naver Map library supports this feature at the native level, so no additional external libraries are needed.
</Callout>

## Basic Clustering Implementation

Naver Map clustering can be configured through the `clusters` property of the `NaverMapView` component.

### 1. ClusterMarkerProp Type Definition

Each marker to be included in the cluster must comply with the `ClusterMarkerProp` type:

```tsx
import type { ClusterMarkerProp } from '@mj-studio/react-native-naver-map';

const clusterMarkers: ClusterMarkerProp[] = [
  {
    identifier: 'marker-1',
    latitude: 37.5665,
    longitude: 126.9780,
    image: { symbol: 'red' }, // Or { httpUri: 'https://...' }, { assetName: 'marker' } etc.
    width: 40,
    height: 40,
  },
  {
    identifier: 'marker-2',
    latitude: 37.5675,
    longitude: 126.9785,
    image: { symbol: 'blue' },
    width: 40,
    height: 40,
  },
  // ... more markers
];
```

### 2. Basic Clustering Implementation

```tsx
import React, { useState, useMemo } from 'react';
import { View } from 'react-native';
import { NaverMapView, type ClusterMarkerProp } from '@mj-studio/react-native-naver-map';

const ClusteredMapExample = () => {
  // Generate marker data
  const clusterMarkers = useMemo<ClusterMarkerProp[]>(() => {
    return generateMarkerData().map((marker, index) => ({
      identifier: `marker-${index}`,
      latitude: marker.latitude,
      longitude: marker.longitude,
      image: { httpUri: `https://picsum.photos/32/32?random=${index}` },
      width: 32,
      height: 32,
    }));
  }, []);

  // Cluster configuration
  const clusters = useMemo(() => [
    {
      width: 50,          // Width of cluster marker
      height: 50,         // Height of cluster marker
      markers: clusterMarkers,
      screenDistance: 40, // Screen distance criteria for clustering (pixels)
      minZoom: 5,         // Minimum zoom level for clustering
      maxZoom: 18,        // Maximum zoom level for clustering
      animate: true,      // Cluster expand/collapse animation
    }
  ], [clusterMarkers]);

  return (
    <NaverMapView
      style={{ flex: 1 }}
      initialCamera={{
        latitude: 37.5665,
        longitude: 126.9780,
        zoom: 10,
      }}
      clusters={clusters}
      onTapClusterLeaf={({ markerIdentifier }) => {
        console.log('Marker clicked:', markerIdentifier);
      }}
    />
  );
};
```

## Advanced Clustering Configuration

### Style Aggregate Cluster Markers

Set `image`, `width`, `height`, and `caption` on a cluster group to style the aggregate markers that represent multiple nearby items. These properties do not change the individual leaf markers in `markers`; each leaf continues to use its own `image`, `width`, and `height`.

```tsx
import {
  type ClusterMarkerCaption,
  NaverMapView,
} from '@mj-studio/react-native-naver-map';

const clusterCaption = {
  color: '#fde047',
  haloColor: '#111827',
  textSize: 16,
  align: 'Center',
} satisfies ClusterMarkerCaption;

<NaverMapView
  style={{ flex: 1 }}
  clusters={[
    {
      image: { symbol: 'red' },
      width: 64,
      height: 64,
      caption: clusterCaption,
      markers: clusterMarkers,
    },
  ]}
/>
```

The example omits `caption.text`, so each aggregate marker displays its current member count. Set `text` to a string to display the same static text on every aggregate marker in the group, or set it to an empty string to hide the caption. Dynamic text formatters and React content are not supported.

When `caption` is omitted, the SDK displays the member count in the center using white text, a transparent halo, text size `12`, requested width and offset `0`, and the full `0` to `21` caption zoom range. An omitted field in a partial `caption` object keeps the same default. Caption fields use the same names and units as marker captions: `requestedWidth`, `align`, `offset`, `color`, `haloColor`, `textSize`, `minZoom`, and `maxZoom`.

`width` and `height` use React Native logical layout units. If `image` is omitted, the SDK selects its low-, medium-, or high-density cluster icon from the member count. When image resolution returns no image, such as for an unknown symbol or a failed URI load, the marker uses the green fallback image. Asset and network images are loaded before the cluster group is attached, so the group's aggregate and leaf markers wait for that image result. Prefer a bundled asset or a built-in symbol when the group must appear without a network dependency.

Changing the group image, caption, or dimensions rebuilds that cluster group with the new style. Styling does not change the SDK's default aggregate-marker tap behavior, which zooms the map until the cluster unfolds.

### Multiple Cluster Groups

You can use multiple cluster groups with different configurations simultaneously:

```tsx
const multiClusters = useMemo(() => [
  {
    // First cluster group - regular markers
    width: 40,
    height: 40,
    markers: regularMarkers,
    screenDistance: 50,
    minZoom: 5,
    maxZoom: 15,
    animate: true,
  },
  {
    // Second cluster group - special markers
    width: 60,
    height: 60,
    markers: specialMarkers,
    screenDistance: 80,
    minZoom: 8,
    maxZoom: 20,
    animate: false,
  }
], [regularMarkers, specialMarkers]);
```

## Cluster Event Handling

### Individual Marker Click Events

You can handle events when individual markers included in clusters are clicked:

```tsx
<NaverMapView
  clusters={clusters}
  onTapClusterLeaf={({ markerIdentifier }) => {
    // Use markerIdentifier to display detailed information about the marker
    const markerData = findMarkerById(markerIdentifier);
    showMarkerDetail(markerData);
  }}
/>
```

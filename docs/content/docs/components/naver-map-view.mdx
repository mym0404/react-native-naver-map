## Overview

NaverMapView is the main component that enables the use of Naver Map SDK in React Native.
It provides core map functionality including map display, camera control, gesture handling, and overlay management.

## Basic Usage

```tsx
import { NaverMapView } from '@mj-studio/react-native-naver-map'; // [!code highlight]

function MyMap() {
  return (
    <NaverMapView // [!code highlight]
      style={{ flex: 1 }} // [!code highlight]
      initialCamera={{ // [!code highlight]
        latitude: 37.50497126, // [!code highlight]
        longitude: 127.04905021, // [!code highlight]
        zoom: 14, // [!code highlight]
      }} // [!code highlight]
      mapType="Basic" // [!code highlight]
      layerGroups={{ // [!code highlight]
        BUILDING: true, // [!code highlight]
        TRAFFIC: false, // [!code highlight]
      }} // [!code highlight]
    />
  );
}
```

### Map Initialization and Initial Data Loading

`onInitialized` reports that the native map object is ready. `onMapLoaded` reports that the same native map instance has loaded its initial map data and displayed it for the first time.

```tsx
<NaverMapView
  style={{ flex: 1 }}
  onInitialized={() => console.log('Map initialized')}
  onMapLoaded={() => console.log('Initial map data loaded')}
/>
```

`onMapLoaded` is called once per native map instance. It is not called again when camera movement or option changes load more data, and adding the handler after the initial load does not replay the event. Its order relative to `onInitialized` is not guaranteed. It also does not report whether the current frame is fully rendered or whether rendering is stable.

### Observing Map Rendering

`onMapRendered` is called after the native SDK renders a map frame. `isFullyRendered` reports whether all data needed for that frame was rendered, while `isRenderingStable` reports whether the SDK needs no additional rendering.

```tsx
<NaverMapView
  style={{ flex: 1 }}
  onMapRendered={({ isFullyRendered, isRenderingStable }) => {
    console.log({ isFullyRendered, isRenderingStable });
  }}
/>
```

The two values are independent SDK states. Do not assume a relationship or transition order between them, or that either value must become `false`. Unlike the one-time `onMapLoaded` event, `onMapRendered` can run repeatedly and more frequently than camera change events. Avoid heavy work or unconditional state updates in this callback. A handler added later receives future rendered frames only; it does not replay a previous frame or provide a separate status query.

### With Camera Control

```tsx
import { useRef, useState } from 'react';
import { NaverMapView, type NaverMapViewRef } from '@mj-studio/react-native-naver-map';
import { Button } from 'react-native';

function MapWithControls() {
  const mapRef = useRef<NaverMapViewRef>(null); // [!code highlight]
  const [camera, setCamera] = useState({
    latitude: 37.498040483,
    longitude: 127.02758183,
    zoom: 14,
  });

  const moveToGangnam = () => {
    mapRef.current?.animateCameraTo({ // [!code highlight]
      latitude: 37.498040483, // [!code highlight]
      longitude: 127.02758183, // [!code highlight]
      zoom: 16, // [!code highlight]
      duration: 1000, // [!code highlight]
      easing: 'EaseIn', // [!code highlight]
    }); // [!code highlight]
  };

  return (
    <>
      <NaverMapView
        ref={mapRef} // [!code highlight]
        style={{ flex: 1 }}
        camera={camera} // [!code highlight]
        onCameraChanged={(event) => { // [!code highlight]
          console.log('Camera changed:', event); // [!code highlight]
          setCamera({ // [!code highlight]
            latitude: event.latitude, // [!code highlight]
            longitude: event.longitude, // [!code highlight]
            zoom: event.zoom, // [!code highlight]
          }); // [!code highlight]
        }} // [!code highlight]
      />
      <Button onPress={moveToGangnam} title="Move to Gangnam" />
    </>
  );
}
```

### Handling Map Symbol Taps

Use `onTapSymbol` to handle taps on map symbols, such as places shown by the map. The callback receives the symbol's `caption`, `latitude`, and `longitude` on Android and iOS.

```tsx
<NaverMapView
  style={{ flex: 1 }}
  onTapSymbol={({ caption, latitude, longitude }) => {
    console.log('Symbol tapped:', caption, latitude, longitude);
  }}
/>
```

When `onTapSymbol` is set, a symbol tap is consumed and does not call `onTapMap`. Without it, the tap is passed to `onTapMap` if that callback is set. For marker overlays you add yourself, use the overlay's `onTap` callback instead.

### Handling Map Long Presses

Use `onLongTapMap` to handle a long press on the map. The callback receives the pressed location as `latitude` and `longitude`, plus `x` and `y` relative to the map view. The screen coordinates use DP on Android and PT on iOS, so you can pass them directly to `screenToCoordinate`.

```tsx
<NaverMapView
  style={{ flex: 1 }}
  onLongTapMap={({ latitude, longitude, x, y }) => {
    console.log('Map long-pressed:', latitude, longitude, x, y);
  }}
/>
```

### With Markers

```tsx
import { NaverMapView, NaverMapMarkerOverlay } from '@mj-studio/react-native-naver-map';
import { View, Text } from 'react-native';

function MapWithAllMarkerTypes() {
  return (
    <NaverMapView
      style={{ flex: 1 }}
      initialCamera={{
        latitude: 33.39530773,
        longitude: 126.54656715029,
        zoom: 8,
      }}
    >
      {/* 1. Symbol Marker */}
      <NaverMapMarkerOverlay
        latitude={33.39530773}
        longitude={126.54656715029}
        image={{ symbol: 'green' }} // [!code highlight]
        anchor={{ x: 0.5, y: 1 }}
        caption={{ text: 'Symbol Marker' }}
      />

      {/* 2. Local Asset Marker */}
      <NaverMapMarkerOverlay
        latitude={33.41}
        longitude={126.55}
        image={require('./logo.png')} // [!code highlight]
        width={50}
        height={50}
        caption={{ text: 'Local Asset' }}
      />

      {/* 3. Native Asset Marker */}
      <NaverMapMarkerOverlay
        latitude={33.35}
        longitude={126.53}
        image={{ assetName: 'thumbnail' }} // [!code highlight]
        width={40}
        height={40}
        caption={{ text: 'Native Asset' }}
      />

      {/* 4. HTTP Image Marker */}
      <NaverMapMarkerOverlay
        latitude={33.32}
        longitude={126.58}
        image={{ httpUri: 'https://picsum.photos/100/100' }} // [!code highlight]
        width={50}
        height={50}
        caption={{ text: 'HTTP Image' }}
      />

      {/* 5. Custom View Marker */}
      <NaverMapMarkerOverlay
        latitude={33.38}
        longitude={126.51}
        width={80}
        height={80}
      >
        <View
          collapsable={false} // [!code highlight]
          style={{
            backgroundColor: 'white',
            padding: 10,
            borderRadius: 8,
            shadowColor: '#000',
            shadowOpacity: 0.2,
          }}
        >
          <Text>Custom View</Text>
        </View>
      </NaverMapMarkerOverlay>
    </NaverMapView>
  );
}
```
